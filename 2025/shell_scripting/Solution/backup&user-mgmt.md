
# 💡 How to use backup.sh

### 💡 How to use:
1. Save this script as backup.sh:
2. Make it executable:
```bash
chmod +x backup.sh.
```
3. Run it by providing the directory you want to back up:
```bash
./backup.sh /path/to/your/target-directory
```
